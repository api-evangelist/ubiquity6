# Ubiquity6

> Ubiquity6 was a San Francisco augmented-reality startup ("Capture & Edit Reality") backed by Benchmark, First Round, and Index Ventures. It built Display.land, a multiplayer 3D/AR/VR capture and creation platform, and was acquired by Discord in June 2021, after which its products were discontinued. Ubiquity6 never published a public API; this profile is maintained by API Evangelist for the network catalog.
